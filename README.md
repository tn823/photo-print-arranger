## 📌 Tại sao cần Photo Print Arranger?

Khi in ảnh thủ công bằng Word hoặc công cụ in mặc định:
- ❌ Ảnh thường bị kéo giãn tỉ lệ, méo mặt nhân vật/chủ thể.
- ❌ **Ảnh dán vở Bé Ngoan**: Khó cắt hình tròn đều tay, ảnh thường bị mất mặt hoặc lấy quá nhiều cảnh thừa bên ngoài.
- ❌ Kích thước giữa các ảnh không đều nhau, phải căn chỉnh thủ công từng ảnh rất mất thời gian.
- ❌ Dễ bị nhảy trang trắng khi in ấn.

**Photo Print Arranger** giải quyết triệt để các vấn đề trên chỉ với **1 cú click chuột**.

## ✨ Tính năng cốt lõi

| Tính năng | Chi tiết |
| :--- | :--- |
| 🔴 **Ảnh tròn dán sổ Bé Ngoan** | Chuyên biệt cho **khung dán ảnh sổ Bé Ngoan mẫu giáo**, phiếu khen thưởng. Tự động dàn đều **15 – 35 ảnh tròn/trang A4**. |
| 🤖 **AI Nhận diện mặt thông minh (YuNet)** | Tự động phát hiện khuôn mặt bé, căn chỉnh ôm trọn đầu, tóc và vai áo theo **tỉ lệ vàng chân dung**, loại bỏ bối cảnh thừa bên ngoài. |
| ✂️ **Cửa sổ Căn chỉnh trực quan** | Cho phép xem trước nhãn dán thực tế, kéo rê chuột di chuyển tâm, phóng to/thu nhỏ (Zoom) hoặc bấm 1 nút để AI tự tìm lại mặt bé. |
| ✂️ **Viền tròn hướng dẫn cắt kéo** | Tự động vẽ đường viền tròn mỏng nét mờ quanh ảnh, giúp phụ huynh và cô giáo đưa kéo cắt lượn theo một cách chính xác tuyệt đối. |
| 🔲 **Khóa chuẩn tỉ lệ (Aspect Ratio)** | Chế độ in ảnh chữ nhật giữ nguyên 100% tỉ lệ gốc của ảnh, tuyệt đối không bị bóp méo. |
| 📄 **In lặp lại hoặc In danh sách** | Hỗ trợ in 1 ảnh lặp lại đầy 1 trang A4 (20 ảnh cho 1 bé dán dần) HOẶC in danh sách ảnh cả lớp. |
| 📄 **Xuất đa định dạng** | Xuất trực tiếp file **Word (`.docx`)**, **PDF (`.pdf`)** hoặc **Cả hai**. |
| 🎨 **Giao diện Popup hiện đại** | Thiết kế dạng hộp thoại nhỏ gọn, bo góc chuẩn Windows 11, tự động căn giữa màn hình, không cần cuộn trang. |

## 📐 Bảng quy cách bố cục in ấn trên giấy A4

### 1. Bố cục Ảnh tròn (Dán vở Bé Ngoan)
| Đường kính | Chiều giấy | Bố cục lưới | Số ảnh/trang | Ứng dụng |
| :---: | :---: | :---: | :---: | :--- |
| **Ø 4.5 cm** *(Khuyên dùng ⭐)* | **Khổ Dọc** | $5 \times 4$ | **20 ảnh / trang** | **Bự hơn khung một tí**, dán trùm phủ mép khung vở Bé Ngoan cực đẹp |
| **Ø 4.0 cm** | Khổ Dọc / Ngang | $6 \times 4$ / $4 \times 6$ | **24 ảnh / trang** | Chuẩn vừa khít khung tròn in sẵn trên bìa vở |
| **Ø 3.5 cm** | Khổ Dọc | $7 \times 5$ | **35 ảnh / trang** | Khung dán nhỏ, phiếu bé ngoan hàng tuần |
| **Ø 5.0 cm** | Khổ Dọc / Ngang | $5 \times 3$ / $3 \times 5$ | **15 ảnh / trang** | Khung dán kỷ yếu lớn, huy hiệu lưu niệm |

### 2. Bố cục Ảnh chữ nhật tiêu chuẩn
| Số ảnh / trang | Chiều giấy | Bố cục lưới | Kích thước mỗi ảnh | Ứng dụng thực tế |
| :---: | :---: | :---: | :---: | :--- |
| **1 ảnh** | Ngang / Dọc | $1 \times 1$ | Toàn trang A4 | Bằng khen, chứng chỉ, poster nhỏ |
| **2 ảnh** *(Khuyên dùng)* | **Ngang** | $1 \times 2$ | **$\sim 13.5 \times 18.0\text{ cm}$** | Chuẩn khổ ảnh $13 \times 18\text{ cm}$ (cắt đôi tờ A4 là được 2 ảnh cực nét) |
| **2 ảnh** | **Dọc** | $2 \times 1$ | **$\sim 9.6 \times 12.8\text{ cm}$** | Kẹp bìa hồ sơ, học bạ dọc |
| **4 ảnh** | Ngang / Dọc | $2 \times 2$ | **$\sim 9.0 \times 12.0\text{ cm}$** | Ảnh lưu niệm tập thể, ảnh thẻ lớn ($9 \times 12$) |
| **6 ảnh** | Ngang | $2 \times 3$ | **$\sim 6.0 \times 8.0\text{ cm}$** | Ảnh minh họa giáo trình, phiếu theo dõi |
| **8 ảnh** | Ngang | $2 \times 4$ | **$\sim 4.5 \times 6.0\text{ cm}$** | Thẻ học sinh, thẻ nhân viên |

## 🖥️ Hướng dẫn sử dụng

### Cách 1: Sử dụng Giao diện Popup (Khuyên dùng)
- Click đúp vào file **`run.bat`** (hoặc chạy lệnh `python main.py`).
- Thao tác nhanh qua các bước:
  1. **Chọn ảnh**: Bấm `📁 Chọn thư mục ảnh` hoặc `🖼️ Chọn file lẻ`.
  2. **Chọn Kiểu in**:
     - Chọn **`🔴 Ảnh tròn Bé Ngoan`**:
       - Chọn đường kính (Mặc định: `4.5 cm (Chuẩn vở ⭐)`).
       - Tích chọn `In đầy 1 trang A4 (Cho 1 bé)` nếu in 1 ảnh lặp lại 20 lần để dán dần.
       - Bấm **`✂️ Xem & Căn chỉnh ảnh tròn (AI)`** để xem trước, kéo rê chuột hoặc để AI tự tìm mặt bé.
     - Hoặc chọn **`🔲 Ảnh chữ nhật chuẩn`** để in khổ chữ nhật truyền thống.
  3. **Vị trí lưu**: Mặc định lưu cùng thư mục với ảnh gốc.
  4. **Thực thi**: Bấm **`🚀 BẮT ĐẦU TẠO FILE IN ẤN`**. File Word và PDF sẽ được mở ngay sau khi tạo xong!

---

### Cách 2: Sử dụng qua Dòng lệnh (CLI)

```bash
# Ví dụ 1: In ảnh tròn Bé Ngoan 4.5cm, in 1 ảnh đầy cả trang A4 (20 ảnh)
python main.py -i "E:\AnhBe\be_phat.jpg" -m circle -d 4.5 --fill-page -o portrait

# Ví dụ 2: In toàn bộ ảnh tròn cả lớp trong thư mục, đường kính 4.0cm, xuất cả Word & PDF
python main.py -i "E:\AnhLopMauGiao" -m circle -d 4.0 -f both

# Ví dụ 3: In ảnh chữ nhật truyền thống, 2 ảnh/trang khổ ngang
python main.py -i "E:\DOWNLOADS\image" -m rect -c 2 -o landscape -f docx

# Xem tất cả các tham số hỗ trợ
python main.py --help
```

#### Bảng tham số CLI:
| Tham số | Viết tắt | Mặc định | Giải thích |
| :--- | :---: | :---: | :--- |
| `--input` | `-i` | *(Bắt buộc)* | Đường dẫn đến thư mục hoặc file ảnh |
| `--mode` | `-m` | `rect` | Kiểu in: `circle` (ảnh tròn Bé Ngoan) hoặc `rect` (chữ nhật) |
| `--diameter` | `-d` | `4.5` | Đường kính ảnh tròn tính theo cm (`3.5`, `4.0`, `4.5`, `5.0`) |
| `--fill-page` | | `False` | Tự động lặp lại ảnh để in đầy 1 trang A4 (dành cho 1 bé) |
| `--count` | `-c` | `2` | Số ảnh trên 1 trang cho chế độ chữ nhật (`1`, `2`, `4`, `6`...) |
| `--orientation` | `-o` | `landscape` | Chiều giấy: `portrait` (dọc) hoặc `landscape` (ngang) |
| `--format` | `-f` | `docx` | Định dạng xuất: `docx`, `pdf`, `both` |
| `--border` | `-b` | `False` | Thêm viền cắt mờ |
| `--output` | | `Tự động` | Đường dẫn file kết quả xuất ra |
